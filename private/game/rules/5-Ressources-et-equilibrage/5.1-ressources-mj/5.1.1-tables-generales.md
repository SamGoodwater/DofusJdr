# 5.1.1. Tables générales

**Description** : Voici les tables essentielles (difficultés, seuils de dégâts, oppositions) pour trancher vite à ta table — sans te perdre dans les calculs.

> **Règles rapides**
> - Base tes DD sur 15, puis ajuste ±5 selon l'avantage ou le désavantage
> - Dégâts / PV / PA / PM : normes en base (outil **Barèmes de sorts**, [5.3.1](../5.3-tables-de-reference/5.3.1-resistances-et-degats.md))
> - [[kref:characteristic:action_points_creature|PA]]/[[kref:characteristic:movement_points_creature|PM]] des ennemis : alignés sur les personnages de niveau équivalent
> - Utilise les tableaux ci-dessous pour gagner du temps en jeu

## Contenu

- **5.1.1.1. Difficultés standards** : Barèmes pour tâches simples, moyennes, difficiles.
- **5.1.1.2. Seuils de dégâts** : Dégâts moyens par niveau, conseils d'ajustement.
- **5.1.1.3. Oppositions** : Matrices pour tests opposés courants.
- **5.1.1.4. États rapides** : Résumé des effets fréquents (stun, entrave, etc.).

---

## 5.1.1.1. Difficultés standards

Besoin d'un DD en deux secondes ? Ces barèmes t'aident à fixer la difficulté selon ce que tes joueur·euse·s tentent.

### Barème de base

| DD | Difficulté | Exemple |
|----|------------|---------|
| **5** | Très facile | Ouvrir une porte non verrouillée, soulever un objet léger |
| **10** | Facile | Escalader une corde, convaincre un ami, crocheter une serrure simple |
| **15** | Modérée | Escalader une paroi glissante, persuader un inconnu, crocheter une serrure complexe |
| **20** | Difficile | Escalader une paroi verticale, convaincre un ennemi, crocheter une serrure très complexe |
| **25** | Très difficile | Escalader une paroi sans prise, convaincre un roi, crocheter une serrure légendaire |
| **30** | Presque impossible | Escalader une paroi lisse et verticale, convaincre un dieu, crocheter une serrure magique |

### Ajustements rapides

**Facteurs favorables** (-2 à -5 DD) :
- **Outils appropriés** : -2 à -3 DD
- **Aide d'un·e allié·e** : -2 à -3 DD
- **Conditions favorables** : -1 à -2 DD
- **Préparation** : -1 à -2 DD

**Facteurs défavorables** (+2 à +5 DD) :
- **Manque d'outils** : +2 à +3 DD
- **Conditions défavorables** : +1 à +2 DD
- **Urgence** : +1 à +2 DD
- **Obstacles** : +2 à +3 DD

### Par niveau

**Personnages de bas niveau (1-5)** :
- **Actions simples** : DD 10
- **Actions normales** : DD 15
- **Actions difficiles** : DD 20

**Personnages de niveau moyen (6-10)** :
- **Actions simples** : DD 15
- **Actions normales** : DD 20
- **Actions difficiles** : DD 25

**Personnages de haut niveau (11-20)** :
- **Actions simples** : DD 20
- **Actions normales** : DD 25
- **Actions difficiles** : DD 30

> **Exemple MJ**
> - Le groupe veut convaincre un gouverneur (importance élevée) → DD 20.
> - Le groupe dispose de preuves irréfutables → -2 au DD.
> - Le groupe est pressé par le temps → +2 au DD.
> - **DD final** : 20 (les modificateurs s'annulent).

## 5.1.1.2. Seuils de dégâts

Ces repères te servent à calibrer tes combats : ni trop faciles, ni impitoyables.

### Dégâts moyens par niveau

Source de vérité : normes `dommages_spell` (voir [5.3.1](../5.3-tables-de-reference/5.3.1-resistances-et-degats.md) et l’outil **Barèmes de sorts**). Tranches neutres approximatives :

| Niveau | Dégâts moyens par tour | Par sort (3 PA) |
|--------|------------------------|-----------------|
| **1-3** | 2-4 | 1-2 |
| **4-7** | 5-10 | 2-4 |
| **8-11** | 12-18 | 5-7 |
| **12-15** | 22-29 | 8-11 |
| **16-20** | 36-48 | 12-16 |

Conversion en dés (variance) : outil Barèmes ou [5.3.1](../5.3-tables-de-reference/5.3.1-resistances-et-degats.md).

### [[kref:characteristic:life_points_creature|Points de vie]] moyens par niveau

Source de vérité : normes `life_points_creature` (admin Caractéristiques / hub Équilibrage). Tranches approximatives :

| Niveau | [[kref:characteristic:life_points_creature|PV]] moyens | [[kref:characteristic:life_points_creature|PV]] boss |
|--------|-----------|---------|
| **1-3** | 10-20 | 20-35 |
| **4-7** | 20-40 | 40-60 |
| **8-11** | 40-70 | 70-100 |
| **12-15** | 70-110 | 110-160 |
| **16-20** | 110-160 | 160-220 |

### Conseils d'ajustement

**Groupe faible** :
- **Réduire** : Réduire les dégâts de 20-30%
- **[[kref:characteristic:life_points_creature|PV]]** : Réduire les [[kref:characteristic:life_points_creature|PV]] de 20-30%
- **Simplifier** : Simplifier les capacités spéciales

**Groupe puissant** :
- **Augmenter** : Augmenter les dégâts de 20-30%
- **[[kref:characteristic:life_points_creature|PV]]** : Augmenter les [[kref:characteristic:life_points_creature|PV]] de 20-30%
- **Complexifier** : Ajouter des capacités spéciales

**Groupe équilibré** :
- **Standard** : Utiliser les valeurs de base
- **Varier** : Varier les types d'ennemis
- **Adapter** : Adapter selon les forces et faiblesses

## 5.1.1.3. Oppositions

Les tests opposés reviennent souvent — voici les paires les plus courantes pour ne pas hésiter à la table.

### Matrices courantes

**[[kref:characteristic:stealth_creature|Discrétion]] vs [[kref:characteristic:perception_creature|Perception]]** :
- **Usage** : Se cacher, se faufiler
- **Test** : [[kref:characteristic:stealth_creature|Discrétion]] ([[kref:characteristic:agility_creature|Agilité]]) vs [[kref:characteristic:perception_creature|Perception]] ([[kref:characteristic:wisdom_creature|Sagesse]])
- **Résultat** : Le résultat le plus élevé l'emporte

**[[kref:characteristic:persuasion_creature|Persuasion]] vs [[kref:characteristic:insight_creature|Perspicacité]]** :
- **Usage** : Convaincre, mentir
- **Test** : [[kref:characteristic:persuasion_creature|Persuasion]] ([[kref:characteristic:chance_creature|Chance]]) vs [[kref:characteristic:insight_creature|Perspicacité]] ([[kref:characteristic:wisdom_creature|Sagesse]])
- **Résultat** : Le résultat le plus élevé l'emporte

**[[kref:characteristic:athletics_creature|Athlétisme]] vs [[kref:characteristic:athletics_creature|Athlétisme]]** :
- **Usage** : Pousser, tirer, lutter
- **Test** : [[kref:characteristic:athletics_creature|Athlétisme]] ([[kref:characteristic:strength_creature|Force]]) vs [[kref:characteristic:athletics_creature|Athlétisme]] ([[kref:characteristic:strength_creature|Force]])
- **Résultat** : Le résultat le plus élevé l'emporte

**[[kref:characteristic:intimidation_creature|Intimidation]] vs [[kref:characteristic:intimidation_creature|Intimidation]]** :
- **Usage** : Menacer, imposer
- **Test** : [[kref:characteristic:intimidation_creature|Intimidation]] ([[kref:characteristic:strength_creature|Force]]/[[kref:characteristic:chance_creature|Chance]]) vs [[kref:characteristic:intimidation_creature|Intimidation]] ([[kref:characteristic:strength_creature|Force]]/[[kref:characteristic:chance_creature|Chance]])
- **Résultat** : Le résultat le plus élevé l'emporte

### Gestion des égalités

**Règle** : Si les résultats sont identiques, la situation reste inchangée — personne ne prend l'avantage.

**Exemples** :
- **[[kref:characteristic:stealth_creature|Discrétion]] vs [[kref:characteristic:perception_creature|Perception]]** : Si égalité, le personnage caché n'est pas détecté mais ne progresse pas
- **[[kref:characteristic:persuasion_creature|Persuasion]] vs [[kref:characteristic:insight_creature|Perspicacité]]** : Si égalité, la négociation reste bloquée
- **[[kref:characteristic:athletics_creature|Athlétisme]] vs [[kref:characteristic:athletics_creature|Athlétisme]]** : Si égalité, aucun des deux ne progresse

## 5.1.1.4. États rapides

Un pense-bête des effets qui reviennent le plus souvent — pratique quand tu veux trancher sans feuilleter les règles.

### États positifs

**Bénédiction** :
- **Effet** : +1d4 aux jets d'attaque et de sauvegarde
- **Durée** : 1 minute
- **Source** : Sorts, potions

**Protection** :
- **Effet** : Réduction des dégâts
- **Durée** : Variable
- **Source** : Sorts, équipements

**Hâte** :
- **Effet** : +2 [[kref:characteristic:movement_points_creature|PM]], action bonus
- **Durée** : 1 minute
- **Source** : Sorts, potions

### États négatifs

**Stun** :
- **Effet** : Ne peut pas agir, désavantage à la [[kref:characteristic:armor_class_creature|CA]]
- **Durée** : 1 tour ou jusqu'à sauvegarde
- **Source** : Sorts, capacités

**Entrave** :
- **Effet** : Vitesse réduite à 0, désavantage à l'esquive
- **Durée** : Variable
- **Source** : Sorts, capacités, pièges

**Ralentissement** :
- **Effet** : Vitesse réduite de moitié, -2 [[kref:characteristic:movement_points_creature|PM]]
- **Durée** : Variable
- **Source** : Sorts, capacités

**Empoisonnement** :
- **Effet** : Dégâts de poison chaque tour, désavantage aux tests
- **Durée** : Variable
- **Source** : Poisons, sorts

**Brûlure** :
- **Effet** : Dégâts de feu chaque tour
- **Durée** : Variable
- **Source** : Feu, sorts de feu

**Gel** :
- **Effet** : Vitesse réduite, dégâts de froid
- **Durée** : Variable
- **Source** : Froid, sorts de glace

### États neutres

**Pesanteur** :
- **Effet** : Ne peut pas être déplacé
- **Durée** : Variable
- **Source** : Sorts, capacités
- **Note** : Peut être bénéfique ou néfaste selon le contexte

**Invisibilité** :
- **Effet** : Invisible, avantage aux attaques
- **Durée** : Variable
- **Source** : Sorts, capacités, équipements

---

### À retenir

- Par défaut, pars sur **DD 15** puis ajuste par paliers de 5.
- Les dégâts moyens augmentent d'environ 10 tous les 4 niveaux.
- Ajuste la difficulté en agissant sur **les dégâts, les [[kref:characteristic:life_points_creature|PV]] et la complexité** plutôt que sur un seul paramètre.
- Note tes propres variantes (ex : table maison des états) pour accélérer tes parties.
