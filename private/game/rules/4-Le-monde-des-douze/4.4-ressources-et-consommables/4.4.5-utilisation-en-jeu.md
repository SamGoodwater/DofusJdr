# 4.4.5. Utilisation en jeu

**Description** : Comment tu utilises tes consommables à la table (temps d'action, limites, effets de bord), et comment ça dialogue avec tes métiers et ta fabrication.

> **Règles rapides - Utilisation en jeu**
> - **Temps** : En combat **1 PA** en général (parfois action bonus) ; hors combat, temps libre
> - **Limites** : même type d'effet = **pas de cumul entre consommables** (le meilleur gagne) ; effets différents se cumulent
> - **Durée** : buffs jusqu’au prochain repos long (8 h max), sauf si l’effet est dépensé avant
> - **Effets secondaires** : Malus potentiels, dépendances (usage excessif)
> - **Métiers** : Qui peut fabriquer/utiliser, certifications (compétences requises)

## Contenu

Comment consommer sans te tirer une balle dans le pied :

- **4.4.5.1. Temps d'utilisation** : Action requise, restrictions en combat.

## 4.4.5.1. Temps d'utilisation

Consommer quelque chose prend du temps — et en plein combat, ton MJ peut te rappeler que « avaler une fiole en catimini », ça se mérite.

### Action requise

**Action standard** :
- **Temps** : En combat, **1 PA** en général (voir [3.2.2 — Utiliser un objet](../../../3-Jouer/3.2-combat/3.2.2-tour-de-jeu-et-actions.md))
- **Consommables** : La plupart des potions et nourritures
- **Exemples** : Potions, nourritures de base

**Action bonus** :
- **Temps** : Utilise une action bonus (coûte moins de [[kref:characteristic:action_points_creature|PA]])
- **Consommables** : Certains consommables peuvent être utilisés comme action bonus
- **Exemples** : Certaines potions rapides, gadgets simples

**Temps libre** :
- **Temps** : Peut être utilisé pendant le temps libre
- **Consommables** : Consommables non urgents
- **Exemples** : Nourritures, potions de buff hors combat

### Restrictions en combat

**Combat actif** :
- **Restrictions** : Certains consommables ne peuvent pas être utilisés en combat actif
- **Raisons** : Nécessitent du temps ou de la concentration
- **Exemples** : Parchemins complexes, préparations longues

**Combat non significatif** :
- **Flexibilité** : Plus de flexibilité dans l'utilisation
- **Temps** : Temps moins restrictif
- **Exemples** : Utilisation plus libre des consommables

**Urgence** :
- **Consommables rapides** : Certains consommables peuvent être utilisés rapidement
- **Coût** : Coût généralement plus élevé
- **Exemples** : Potions d'urgence, gadgets tactiques

## 4.4.5.2. Limites

On te laisse te goinfrer de potions… mais pas sans règle : sinon tout le monde devient invincible et l'aventure s'endort.

### Stack d'effets

**Règle générale** : Les effets de même type **issus de consommables** ne se cumulent pas.

**Meilleur effet** : Si plusieurs consommables donnent le même type d'effet, seul le meilleur effet s'applique. Boire une deuxième bière n’ajoute rien ; une potion de grand bouclier remplace une potion de bouclier plus faible.

**Effets différents** : Les effets de types différents peuvent se cumuler (café + bière, bouclier + PV temporaires).

**Limites de caractéristiques** : un bonus ou malus de consommable est temporaire. Il s'applique après la partie permanente bornée (par exemple ±15 pour une compétence ou une sauvegarde de PJ/PNJ) et peut la dépasser. La couche temporaire vaut 0 lorsqu'aucun effet n'est actif.

**Exemples** :
- **Deux potions de bouclier** : Seule la meilleure s'applique
- **Bière + Café** : Les deux s'appliquent (Supercherie et Investigation)

### Saturation

**Limite de consommation** :
- **Par tour** : Limite de consommation par tour
- **Par jour** : Limite de consommation par jour
- **Par type** : Limite par type de consommable

**Conséquences** :
- **Inefficacité** : Consommation excessive peut être inefficace
- **Malus** : Peut causer des malus si trop consommé
- **Équilibre** : Maintient l'équilibre du jeu

### Overdoses

**Définition** : Consommation excessive de consommables peut causer des overdoses.

**Effets** :
- **Malus** : Malus aux caractéristiques ou compétences
- **États** : États négatifs (nausée, confusion, etc.)
- **Durée** : Durée variable selon la gravité

**Prévention** :
- **Modération** : Consommation modérée recommandée
- **Temps** : Espacer les consommations
- **Variété** : Varier les types de consommables

## 4.4.5.3. Effets secondaires

Même une potion peut avoir son petit prix : fatigue, interactions bizarres, ou mauvais combo avec un autre truc que tu viens d'avaler.

### Malus potentiels

**Types** :
- **Malus temporaires** : Malus aux caractéristiques ou compétences
- **États négatifs** : États négatifs (fatigue, nausée, etc.)
- **Dépendances** : Risque de dépendance

**Exemples** :
- **Potion puissante** : Peut causer de la fatigue après usage
- **Potion magique** : Peut causer des effets secondaires magiques
- **Potion de force** : Peut causer de la faiblesse après expiration

### Dépendances

**Risque** :
- **Usage répété** : Usage répété peut créer une dépendance
- **Symptômes** : Symptômes de manque si arrêt
- **Traitement** : Nécessite un traitement pour guérir

**Gestion** :
- **Modération** : Modération dans l'usage
- **Alternatives** : Utiliser des alternatives
- **Traitement** : Chercher un traitement si dépendance développée

### Interactions

**Interactions entre consommables** :
- **Compatible** : Certains consommables sont compatibles
- **Incompatible** : Certains consommables sont incompatibles
- **Risques** : Interactions peuvent causer des effets imprévus

**Interactions avec sorts** :
- **Renforcement** : Certains consommables renforcent les sorts
- **Affaiblissement** : Certains consommables affaiblissent les sorts
- **Annulation** : Certains consommables annulent les sorts

## 4.4.5.4. Interaction métiers

Fabrication et dégustation, ce n'est pas la même famille de compétences : ton boulanger n'est pas forcément meilleur pour boire tes potions qu'un autre personnage.

### Qui peut fabriquer

**Métiers requis** :
- **Potions** : Alchimiste — c'est le seul métier de récolte qui transforme aussi ce qu'il ramasse
- **Nourritures** : Boulanger (céréales et pâtisseries), Boucher (viandes), Poissonnier (poissons)
- **Gadgets et pièges** : Bricoleur
- **Parchemins** : aucun métier ne les fabrique, ils s'achètent ou se gagnent en quête

**Niveau requis** : les mêmes deux conditions que pour tout objet fabriqué (voir [4.3.3 – Métiers d'artisanat](../4.3-les-metiers/4.3.3-metiers-d-artisanat.md)) :
- **Métier** : ton niveau de métier doit couvrir la **rareté** du consommable
- **Personnage** : ton personnage doit avoir au moins le **niveau** du consommable
- **Exemple** : une potion Rare de niveau 10 demande Alchimiste 3 et un personnage de niveau 10

**Recettes** :
- **Nécessaires** : Recettes nécessaires pour fabriquer
- **Apprentissage** : Apprentissage des recettes requis
- **Création** : Possibilité de créer de nouvelles recettes

### Qui peut utiliser

**Utilisation générale** :
- **Règle** : N'importe quelle créature peut consommer un consommable
- **Restrictions** : Peu de restrictions sur l'utilisation
- **Exceptions** : Certains consommables ont des restrictions

**Restrictions spéciales** :
- **Niveau** : Certains consommables nécessitent un niveau minimum
- **Classe** : Certains consommables sont réservés à certaines classes
- **Caractéristiques** : Certains consommables nécessitent des caractéristiques minimales

### Certifications

**Certifications professionnelles** :
- **Fonction** : Certifications pour certains types de consommables
- **Avantages** : Avantages pour les certifiés
- **Obtention** : Nécessite des tests et une formation

**Exemples** :
- **Certification alchimique** : Pour fabriquer des potions avancées
- **Certification culinaire** : Pour fabriquer des plats spéciaux
- **Certification magique** : Pour fabriquer des parchemins puissants

## Exemples pratiques

### Exemple 1 : Utilisation de potion en combat

**Scénario** : En combat, tu veux utiliser une potion de soin.

**Action** :
- **Temps** : Utilise une action standard (coûte des [[kref:characteristic:action_points_creature|PA]])
- **Effet** : Restaure des [[kref:characteristic:life_points_creature|PV]]
- **Résultat** : [[kref:characteristic:life_points_creature|PV]] restaurés, action utilisée

### Exemple 2 : Stack d'effets

**Scénario** : Tu bois deux bières d'Amakna.

**Action** :
- **Première bière** : +1 [[kref:characteristic:deception_creature|Supercherie]]
- **Deuxième bière** : +1 [[kref:characteristic:deception_creature|Supercherie]] (même type)
- **Résultat** : Seule la meilleure s'applique (ici, une seule : pas de cumul)

### Exemple 3 : Fabrication de consommable

**Scénario** : Tu veux fabriquer une potion de soin Peu commune de niveau 5.

**Conditions** :
- **Métier** : Alchimiste niveau 2 minimum (la rareté Peu commune ouvre au niveau 2)
- **Personnage** : Niveau 5 minimum (le niveau de la potion)
- **Recette** : Dois connaître la recette
- **Ressources** : Dois avoir les ressources nécessaires
- **Atelier** : Dois avoir accès à un atelier d'alchimie
